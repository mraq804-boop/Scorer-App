# App Look and Feel Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make the PWA feel like a mobile app:
- a navy top bar and a bottom tab bar (Home, My team, the gold +, Stats, Account) on every screen except New match and scoring;
- Home, New match, My team and Account redone as app screens;
- full-screen install polish.

**Architecture:**
- **One `TabBar` client component in the root layout.** It decides from the path whether to show itself (`showsTabBar`) and which tab is active (`tabForPath`). It reads the Stats target from `localStorage` only, never Dexie, so the public bundles stay light.
- **Each screen renders its own `AppBar`.** It's a server-safe component: title, optional back or close link, optional actions.
- **Navigation stays as ordinary links,** for offline safety. Smoothness comes from cross-document View Transitions in CSS.
- **My team splits into sections** chosen by `?section=` through client navigation (`router.push`), so the loaded team stays in memory and the back button works.

**Tech Stack:** Next.js 16 App Router, React 19, Tailwind 4, the existing shadcn `Drawer` (vaul), `next-themes`, lucide icons, vitest and Playwright. No new dependencies.

**Spec:** `docs/superpowers/specs/2026-10-29-app-feel-design.md`

**Interfaces:**
- **Produces in `src/lib/app/frame.ts` (pure, no imports from `@/lib/local`):**
  ```ts
  export type TabKey = "home" | "team" | "new" | "stats" | "account";
  export function tabForPath(pathname: string): TabKey | null;
  export function showsTabBar(pathname: string): boolean;
  export const MY_TEAM_KEY = "cricket-scorer:my-team";
  export const LAST_TEAM_KEY = "cricket-scorer:last-team";
  export type TeamCodes = { myTeam: string | null; lastTeam: string | null };
  export function readTeamCodes(storage: Pick<Storage, "getItem"> | null): TeamCodes;
  export function statsHref(codes: TeamCodes): string;
  export function rememberTeamCode(key: string, code: string | null): void;
  ```
  - `tabForPath`:
    - `/` → home;
    - `/team` → team (but `/team/join` → null);
    - `/account` → account;
    - `/t/…` → stats;
    - anything else → null.
  - `showsTabBar` is false for `/new`, `/score`, `/team/join`, `/auth/*` and `/offline`, and true otherwise. `/m/<code>` shows the bar with no tab active.
  - `statsHref` returns `/t/<myTeam>`, else `/t/<lastTeam>`, else `/team`.
  - `rememberTeamCode` writes the code, or removes the key when `null`, inside try/catch. It then dispatches `new Event(TEAM_CODES_EVENT)` on `window`, where `export const TEAM_CODES_EVENT = "cricket-scorer:team-codes"`. The `storage` event only fires in other tabs, so this lets the tab bar on the same page update.
  - `readTeamCodes(null)` and a storage whose `getItem` throws both return both codes as null.
- **Produces in `src/components/app/app-bar.tsx`:**
  ```ts
  type AppBarProps = { title: ReactNode; heading?: boolean; back?: string; close?: string; actions?: ReactNode };
  export function AppBar(props: AppBarProps): JSX.Element;
  ```
  - `heading` makes the title an `h1`; otherwise it's a `span`.
  - `back` renders a chevron link labelled "Back"; `close` renders an ✕ link labelled "Close".
  - It's sticky at the top, `bg-[#1b2340] text-white`, with `pt-[env(safe-area-inset-top)]`, and the title in `<bdi className="truncate">`.
  - It spans the full width outside the `max-w-md` column, with its inner row at `max-w-md`.
- **Produces in `src/components/app/tab-bar.tsx`:** `"use client"; export function TabBar(): JSX.Element | null`.
  - It uses `usePathname()`, `showsTabBar` and `tabForPath`, and reads the Stats href through `useSyncExternalStore(subscribe to "storage" and TEAM_CODES_EVENT, () => statsHref(readTeamCodes(safeLocalStorage())), () => "/team")`. Here `safeLocalStorage()` returns `window.localStorage`, or `null` if accessing it throws.
  - It renders `<nav data-tab-bar aria-label="Tabs">` fixed at the bottom with five links.
  - The active link gets `aria-current="page"`.
  - The + is a 56 px gold circle raised by about 20 px, with `aria-label="New match"` and `href="/new"`.
- **Produces in `src/components/app/share-link-button.tsx`:** `"use client"; export function ShareLinkButton({ url, title }: { url: string; title: string })`.
  - It's an icon button labelled "Share".
  - It calls `navigator.share({ url, title })`, falling back to `navigator.clipboard.writeText(url)` plus `toast(t("app.linkCopied"))`.
  - A cancelled share does nothing.
